# 🌾 ТД Шихобалова — Цифровая экосистема

Мукомольное производство (Самара, 9000 т/мес). Полная цифровая трансформация.

## 📁 Структура проекта

### 🌐 dov-muka — Двусторонний сайт
- **Backend:** FastAPI + PostgreSQL + SQLAlchemy + Alembic
- **Frontend:** React + TypeScript + Vite
- **Deploy:** Docker + Nginx
- **Модули:** Клиенты, Сделки, Заказы, Продукты, База знаний
- **Части:** Публичная (каталог, контакты) + Админка

### 📱 flourradar — Мобильное приложение
- **Стек:** React + Capacitor + TypeScript
- **Платформа:** Android (готов к APK)
- **Страницы:** Dashboard, Каталог, Клиенты, Аналитика, FlourRadar, Настройки

### 🤖 tg_radar — Telegram-бот мониторинга цен
- **Стек:** Python + aiogram + SQLite
- **Функции:** Парсинг цен конкурентов, фильтры, уведомления
- **База:** radar.db

### 📱 tg_radar_app — Мобильная версия бота
- **Стек:** Python + Kivy/Buildozer
- **Функции:** Локальный клиент для бота

## 🎯 Глобальные цели

1. Выход на стабильные 9000 тонн/месяц
2. Экспорт в Китай и страны СНГ
3. AI-автоматизация: парсинг цен, генерация КП, голосовой агент
4. Интеграция с 1С через n8n
