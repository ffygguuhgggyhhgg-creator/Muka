# Исправления скриптов

Каталог содержит **исправленные тексты скриптов**, а не изменённый проект.
Файлы проекта (`project/`) и точная расшифровка (`decoded/`) не тронуты —
там исходное состояние для сверки.

| Каталог | Содержимое |
|---|---|
| `scripts/` | 268 файлов — обязательные исправления FIX-01…FIX-13 |
| `scripts-optional/` | 122 файла — правки по согласованию OPT-01, OPT-02 |

Обоснование каждой правки — `../docs/05-ошибки-и-исправления.md`.

## Почему нельзя применить автоматически

`Scripts.ssc` — бинарный формат Simple-Scada 2. Прочитать его удалось
(`tools/parse_ssc.py` разбирает 99.7 % байт), но обратной сборки нет, а
рядом лежит скомпилированный байт-код `Scripts/Compiled/*.exs`, который
пересоздаёт только редактор. Правка бинарника вручную гарантированно
испортит проект.

## Порядок применения

1. Сделайте копию каталога проекта (или используйте
   `BKHP_SILKORP_original.rar` как эталон для отката).
2. Откройте проект в редакторе Simple-Scada 2.
3. Для каждого файла из `scripts/` найдите скрипт с тем же именем и
   замените его тело содержимым файла целиком (включая секцию `var`,
   если она есть — в FIX-03 она добавлена).
4. Скомпилируйте проект (редактор пересоберёт `Compiled/*.exs`)
   и проверьте отсутствие ошибок компиляции.
5. Отдельно выполните правки, которые текстом не делаются, — раздел
   D-02 и D-19 в документе по ошибкам:
   * переименование 32 обработчиков либо соответствующих объектов
     мнемосхемы (иначе 11 механизмов не управляются с экрана);
   * переименование объекта `T6CalButton16` → `T4CalButton6`;
   * разведение привязок `mo1DO32`, `mi1DI6`, `t1DI22` по разным
     входам/выходам ПЛК.
6. Правки из `scripts-optional/` применяйте только после согласования:
   OPT-01 меняет регламент предпусковой сигнализации, OPT-02 вводит
   уставку предельного времени калибровки 600 с.

## Порядок проверки на объекте

Обязательный минимум перед вводом в работу:

| Что проверить | Как |
|---|---|
| FIX-01 | нажать аварийный останов при работающих аспирации и транспортёре — всё должно остановиться, а не запуститься |
| FIX-02 | снять питание цепи стоповой кнопки остановленного транспортёра, затем пустить его — пуск должен проходить |
| FIX-03 | открыть задвижку — в журнале должно быть только «Начало открытия…», без «Активна блокировка пуска!» |
| FIX-04 | выполнить калибровку и сверить `CalOpenTime` с фактическим временем хода по секундомеру |
| FIX-05 | нажать кнопку блокировки — состояние должно переключаться, а в журнале быть одно сообщение |
| FIX-12 | при активной аварии нории нажать сброс — состояние должно сняться, если вход аварии уже снят |
| OPT-01 | пустить механизм, затем в течение 20 с пустить второй — сирена должна отработать заново |
| OPT-02 | имитировать отказ концевика задвижки — через 600 с алгоритм должен сняться и разблокировать группу |

## Воспроизведение

```bash
cd scada/bkhp-silkorp
python3 tools/apply_fixes.py      # пересоздаёт fixes/ из decoded/
```

Каждая правка проверяет шаблон исходного текста и падает с сообщением,
если текст не совпал, — молча «почти применить» правку невозможно.
