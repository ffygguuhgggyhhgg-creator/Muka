## 3. Семейства тегов механизмов

`X` — индекс механизма; у транспортёров вместо `X` подставляется
`ForwardT<n>` / `ReversT<n>` там, где направление важно.

| Тег | Тип | Группа | Назначение |
|---|---|---|---|
| `StatusX` | Byte | Статусы механизмов | состояние: 1 работа (А), 2 работа (М), 3 стоп (М), 4 стоп (А), 10 авария |
| `StatusStartX` | Byte | Статусы механизмов | заявка: 0 отработана, 1 стоп оператором, 5 заявка на пуск, 6 отмена, 16 стоп по стоповой кнопке |
| `AlarmStatusX` | Boolean | Статусы механизмов | **не используется** (см. дефект D-03) |
| `RelayOutX` | Boolean | Выходные переменные | выход на пускатель |
| `RelayInX` | Boolean | Входные переменные | ответ пускателя |
| `RelayAlarmX` | Boolean | Входные переменные | вход аварии (только нории) |
| `RelayStopInX` | Boolean | Входные переменные | питание цепи стоповой кнопки |
| `MembSensorAT<n>`, `MembSensorBT<n>` | Boolean | Входные переменные | мембранные датчики подпора транспортёра |
| `StartTimeX` | Integer | Таймеры / … / Таймеры старта | счётчик ожидания ответа пускателя (уставка 3 с) |
| `AlarmTimeX` | Integer | Таймеры / … / Таймеры аварий | счётчик удержания входа аварии (уставка 10 с) |
| `StatusAlarmX` | Boolean | Таймеры / … / Таймеры аварий | признак аварии, читается мнемосхемой |
| `RPMTimerT<n>` | Integer | Таймеры / … / контроля оборотов валов | контроль оборотов вала |

## 4. Семейства тегов задвижек

`G` — группа задвижек: `T1`, `T4`, `T4Clap`, `T5`, `T5Clap`, `T6`, `T7`;
`N` — номер задвижки в группе.

| Тег | Тип | Назначение |
|---|---|---|
| `G LatchStatusN` | Boolean | состояние по концевикам (отображение) |
| `G LatchStatusByteN` | Byte | 1 в работе, 2 открыта, 3 закрыта, 4 калибровка, 5 авария |
| `G LatchOpenN` / `G LatchCloseN` | Boolean | концевики «открыто» / «закрыто» |
| `G LatchSelectN` | Boolean | выход выбора задвижки для контроллера |
| `G LatchRunOpen` / `G LatchRunClose` | Boolean | **общие на группу** силовые выходы хода |
| `G BlockSelectStatus` | Boolean | **общий на группу** флаг занятости (сериализация операций) |
| `G OpenStatusN` / `G CloseStatusN` / `G CalStatusN` | Boolean | заявка на операцию, запускает соответствующий алгоритм |
| `G OpenTimerN` / `G CloseTimerN` / `G CalTimerN` | Integer | счётчик такта алгоритма |
| `G LatchCalOpenTimeN` / `G LatchCalCloseTimeN` | Integer | измеренное время хода, уставка тайм-аута |

## 5. Служебные и весовые теги

| Тег | Тип | Назначение |
|---|---|---|
| `ManualStartStatus` | Boolean | алгоритм предпускового оповещения активен |
| `ManualTimer` / `ManualTimerDelay` / `ManualTimerAlarm` | Integer | окно 120 с / задержка 20 с / сирена 10 с |
| `AlarmStatus` | Boolean | общий признак аварии, запускает `Alarm` |
| `AlarmStartTimer` | Integer | такт прерывистого оповещения |
| `Alarm16Level` / `Alarm1Level` | Boolean | выходы сирен 16-го и 1-го этажа (см. D-19) |
| `BlockControl` | Boolean | защитная блокировка связей механизмов |
| `PingPLC16Flor` | Boolean | связь с ПЛК установлена |
| `T<n>TargerFreq` | Single | задание частоты, Гц (опечатка в имени: Targer) |
| `T<n>FreqToPLC` | Single | задание в формате ПЛК, 0…10000 |
| `T<n>Freq` / `T<n>Power` | Single | телеметрия ЧП: частота и ток |
| `L1_D1_Cmd` | Word | команда терминалу: 0 чтение, 1 запись, 2 в работу, 3 стоп цикла, 4 проход |
| `L1_D1_Weight` | Double | текущий вес |
| `L1_D1_S_*` | Word | статусы терминала: Start, Stop, Dose, Pause, Load, UnLoad, Error |
| `L1_D1_C_C` / `L1_D1_C_E` | Double | счётчик весов / счётчик отпуска |
| `L1_D1_C_n` / `_d` / `_P` / `_t` | Double | прочие счётчики терминала |
| `L1_D1_Par_*` | Double | параметры дозирования: TDel, TDampers, WLadel, Capacity, OSigma, TankageLadel |
| `L1_D1_D_In1/2`, `L1_D1_D_Out1/2` | Boolean | дискретные входы/выходы терминала |
| `LatchHighStatus` / `LatchBottomStatus` | Boolean | верхняя / нижняя заслонка бункера весов |
| `Capacity` | Double | производительность, т/ч (`Prod`) |
| `Count` / `Timer` | Double / Integer | база и такт расчёта производительности |
| `LocalCounter` / `CalculateCount` / `LocalCounterTimer` | Double / Integer | локальный счётчик отпуска |
| `ClearLocalCounter` | Boolean | **никем не пишется** (см. дефект D-15) |
| `VesRepFrom` / `VesRepTo` | DateTime | границы интервала отчёта |

## 6. Соглашение по адресации ПЛК

Символы CODESYS в узле `Application.PLC_PRG`:

| Шаблон | Модуль | Пример |
|---|---|---|
| `mi<k>DI<n>` | входы корпуса | `mi0DI1`, `mi1DI6`, `mi3DI4` |
| `mo<k>DO<n>` | выходы корпуса | `mo1DO17` = `RelayOutN1`, `mo1DO32` = сирены |
| `t<k>DI<n>` | входы транспортёра k | `t1DI21`, `t6DI32` |
| `t<k>DO<n>` | выходы транспортёра k | `t4DO…`, `t51DO…` |
| `t<k1>DI/DO<n>` | второй модуль транспортёра | `t41DI…`, `t51DO…` |
| `t<k>Freq`, `t<k>Power`, `t<k>FreqMonitoring` | телеметрия ЧП | `t7Freq` |
