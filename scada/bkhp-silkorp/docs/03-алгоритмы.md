# Алгоритмы проекта

Такт всех периодических скриптов принят равным 1 с — все счётчики в проекте
инкрементируются на 1 за вызов и сравниваются с уставками в секундах
(`ManualTimer >= 120`, «накапливаем секунды» в комментариях автора).

Обозначения: `X` — индекс механизма (`N1…N10`, `C1…C14`, `T1…T20`);
у транспортёров выходы и заявки раздваиваются на `Forward`/`Revers`.

---

## А1. Пуск механизма с предпусковой сигнализацией

**Участники:** `StartButtonX_OnClick` (событие), `ManualStart` (периодический).

```
StartButtonX_OnClick:
    AddMessage('Нажата кнопка пуска (<позиция>)!')
    если RelayOutX = False             // выход контроллера не активен
      и  StatusX  = 4                  // нет местного включения
    то
        если StatusStartX = 5 то StatusStartX := 6      // повторное нажатие = отмена
        иначе StatusStartX := 5;  ManualStartStatus := True

ManualStart (пока ManualStartStatus = True):
    ManualTimer++;  ManualTimerAlarm++;  ManualTimerDelay++
    ManualTimerAlarm <= 10  → Alarm16Level := True,  Alarm1Level := True,  AlarmBox красный
    ManualTimerAlarm >  10  → сирены сняты, AlarmBox серый
    ManualTimerDelay >= 20  → для всех X: если StatusStartX = 5 то
                                  RelayOutX := True;  StatusStartX := 0
    ManualTimer     >= 120  → ManualStartStatus := False; все три таймера := 0
                              AddMessage('Сброс таймера оповещения о пуске механизмов')
```

Смысл: 10 с звуковое оповещение, с 20-й секунды выдача команд, окно активности
алгоритма 120 с. `ManualStart` обслуживает N1…N9, C1…C12, T1…T18
(прямой и реверс отдельными заявками).

> Дефект D-06: повторное нажатие пуска, пока окно 120 с ещё открыто, выдаёт
> команду немедленно и без сигнализации.

## А2. Останов механизма

```

    если RelayOutX = True  то StatusStartX := 1;  RelayOutX := False
    если StatusStartX = 5  то StatusStartX := 6           // снятие необработанной заявки
```

У транспортёра снимаются оба направления.

## А3. Групповой аварийный останов и сброс аварий

```
AlarmStopButton_OnClick:      RelayOutX := False,  StatusStartX := 6   для всех X
AlarmDropButton_OnClick:      сброс признака аварии, StatusStartX := 1, StatusX := 4
```

> Дефект D-01: в исходнике аварийный останов ставит `True` (то есть **включает**)

> который читает мнемосхема, — `StatusAlarmX`.

## А4. Контроль пускателя и расчёт состояния (MnemoControlN / C / T)

Периодический скрипт, по блоку на каждый механизм:

```
если StatusAlarmX = False то
    (RelayOutX=1, RelayInX=1) → StatusX := 1; StartTimeX := 0; мнемосхема зелёная
    (RelayOutX=0, RelayInX=1) → StatusX := 2; StartTimeX := 0; жёлтая
    (RelayOutX=1, RelayInX=0) → красная; StartTimeX++
                                 если StartTimeX > 3 то
                                     RelayOutX := False; StatusStartX := 6
                                     StatusX := 3; StartTimeX := 0
    (RelayOutX=0, RelayInX=0) → StatusX := 4; красная
иначе StatusX := 10                                  // авария
```

Смысл ветви (1,0): пускатель не подтвердил включение за 3 с — команда снимается.

Блок аварии в том же скрипте:

```
если RelayAlarmX = True то
    AlarmTimeX++
    если AlarmTimeX >= 10 то RelayOutX := False; AlarmStatus := True
                             StatusAlarmX := True; AlarmTimeX := 0
если RelayAlarmX = False то StatusAlarmX := False; AlarmTimeX := 0
```

То есть авария фиксируется при удержании входа 10 с и снимается автоматически
по исчезновению входа.

> Наблюдение D-09: код 3 «Стоп (М)» практически недостижим — ветвь (0,0)
> выполняется в том же проходе после снятия выхода и перезаписывает его на 4.

## А5. Контроль питания стоповых кнопок (StopButtonsControl)

```

        если StatusX = 1 и RelayStopInX = False то
            RelayOutX := False;  StatusStartX := 16
```

## А6. Аварийная звуковая сигнализация (Alarm)

Периодический скрипт, пока `AlarmStatus = True`, ведёт прерывистое оповещение
по такту `AlarmStartTimer`:

| Такт | Действие |
|---|---|
| 1 | сирены включены, `AlarmBox` красный |
| 2 | сирены выключены, `AlarmBox` серый |
| 4 | включены |
| 6 | выключены |
| 8 | включены |
| 10 | выключены, `AlarmStartTimer := 0`, `AlarmStatus := False` |

## А7. Контроль связи с контроллером

## А8. Открытие задвижки (T\*OpenScriptN)

```
T*OpenButtonN_OnClick:
    если CalOpenTimeN > 0                  // калибровка выполнена
      и  BlockSelectStatus = False          // группа задвижек свободна
      и  LatchStatusByteN < 5               // нет аварии
    то  OpenStatusN := True;  BlockSelectStatus := True
        AddMessage('Начало открытия задвижки <позиция>!')
    если CalOpenTimeN = 0 то AddMessage('Произведите калибровку открытия!…')

T*OpenScriptN (пока OpenStatusN = True):
    OpenTimerN++
    такт 3   (>2 и <4) : BlockSelectStatus := True; LatchStatusByteN := 1;
                          LatchSelectN := True
    такт 6   (>5 и <7) : LatchRunOpen := True
    LatchOpenN = True  : LatchRunOpen := False; BlockSelectStatus := False
                          LatchStatusByteN := 2; OpenStatusN := False
                          LatchSelectN := False; OpenTimerN := 0
                          AddMessage('… успешно открыта!')
    OpenTimerN > 9 + CalOpenTimeN :
                          LatchRunOpen := False; BlockSelectStatus := False
                          LatchStatusByteN := 5 (авария); OpenStatusN := False
                          LatchSelectN := False; OpenTimerN := 0
                          AddMessage('Авария задвижки …, проверьте концевой выключатель')
```

Закрытие (`T*CloseScriptN`) построено зеркально: выход `LatchRunClose`,
концевик `LatchCloseN`, успешное завершение даёт `LatchStatusByteN := 3`,
таймаут `> 9 + CalCloseTimeN` — состояние 5.

> Дефект D-05: у 194 скриптов кнопок задвижек после успешного старта
> безусловно выдаётся ложное «Активна блокировка пуска!».

## А9. Калибровка хода задвижки (T\*CalScriptN)

```
T*CalButtonN_OnClick: те же проверки, CalStatusN := True; BlockSelectStatus := True

T*CalScriptN (пока CalStatusN = True):
    CalTimerN++
    такт 3:  если LatchStatusByteN = 3 (закрыта) то
                 CalOpenTimeN := 0; CalCloseTimeN := 0
                 BlockSelectStatus := True; LatchStatusByteN := 4 (калибровка)
                 LatchSelectN := True
             если LatchStatusByteN = 2 (открыта) то
                 CloseStatusN := True          // сначала автозакрытие
                 AddMessage('… не закрыта! Повторите команду калибровки…')
                 CalStatusN := False; CalTimerN := 0
    такт 6:  LatchRunOpen := True
    пока LatchRunOpen: CalOpenTimeN++                       // измерение времени открытия
    LatchOpenN = True: LatchRunOpen := False
    далее:   LatchRunClose := True, AddMessage('… успешно открыта при калибровке!')
    пока LatchRunClose: CalCloseTimeN++                     // измерение времени закрытия
    LatchCloseN = True: LatchRunClose := False; BlockSelectStatus := False
                        LatchStatusByteN := 3; CalStatusN := False
                        LatchSelectN := False; CalTimerN := 0
                        AddMessage('… успешно закрыта при калибровке! Калибровка выполнена!')
```

Полученные `CalOpenTimeN` и `CalCloseTimeN` затем служат уставками таймаутов
в алгоритмах открытия и закрытия (`9 + CalTime`) и выводятся `T*CalValueBar`.

> Дефект D-07: время открытия завышалось на 1 с из-за двойного инкремента.
> Дефект D-08: в калибровке нет тайм-аута — при неисправном концевике алгоритм
> и блокировка группы задвижек висят бесконечно.

## А11. Весовой терминал, производительность и счётчики

```
Кнопки → L1_D1_Cmd:  VesRead 0 · VesWrite 1 · VesInWork 2 · VesStopCircle 3 · VesThrue 4

Indicators (периодический) — лампы по L1_D1_S_Start / S_Stop / S_Pause / S_Error,
    текст и цвет состояния верхней и нижней заслонок по LatchHighStatus /
    LatchBottomStatus («Закрыта» / «Открыта»)
StartVesIndicators (при запуске проекта) — то же плюс Capacity := 0

Prod (периодический) — производительность по приращению счётчика весов:
    Timer++
    Timer < 2               → Count := L1_D1_C_C            // база
    L1_D1_C_C > Count       → Capacity := (L1_D1_C_C - Count) * 3600 / (Timer - 1) / 1000
                              Timer := 0
ErrorCapacitControl (периодический):
    Capacity > 34 и < 100   → ErrorCapacityImage красный + аларм «Убавьте подачу!»
    Capacity < 34           → ErrorCapacityImage серый
CalculateLocalCounter (периодический) — локальный счётчик отпуска:
    LocalCounterTimer++
    LocalCounterTimer < 2   → CalculateCount := L1_D1_C_E
    L1_D1_C_E > CalculateCount → LocalCounter += (L1_D1_C_E - CalculateCount)
                                 LocalCounterTimer := 0
ClearLocalCounterButton_OnClick: если ClearLocalCounter = True то LocalCounter := 0
VesErrorOff_OnClick:  L1_D1_S_Error := 1
VesRepValueButton_OnClick:     ReportBuild('VesReport').View(GetClientName)
VesRepIntervalButton_OnClick:  ReportBuild('VesReportInterval').View(GetClientName)
```

> Дефекты D-10 (деление на нуль и «залипание» производительности),
> D-11 (провал уставки подачи при Capacity ≥ 100),
> D-13 (потеря импульсов локального счётчика),
> D-14 (кнопка сброса ошибки весов ставит ошибку),
> D-15 (кнопка сброса локального счётчика не работает).
