# БКХП «SilKorp» — проект Simple-Scada 2

Импорт присланного архива `BKHP SILKORP для доработки.rar` + машинно-читаемая
расшифровка бинарных файлов проекта.

**Проект:** `BKHP SILKORP 30.05.26 Актуальная`
**SCADA:** Simple-Scada 2 (формат `.spr/.svr/.spg/.swn/.ssc`)
**Отчёты:** Stimulsoft Reports (`.mrt`)

## Структура каталога

| Путь | Что это |
|------|---------|
| `BKHP_SILKORP_original.rar` | исходный архив без изменений (эталон) |
| `project/` | распакованный проект Simple-Scada (бинарный, открывается в редакторе SCADA) |
| `decoded/scripts/*.pas` | 579 скриптов, извлечённых из `Scripts.ssc` в виде текста |
| `decoded/variables.tsv` | 1419 тегов: имя + описание |
| `decoded/messages.txt` | список сообщений/алармов |
| `decoded/project.txt` | строки из `Project.spr` (БД, OPC-серверы, единицы измерения) |
| `tools/dump_simplescada.py` | декодер длино-префиксных UTF-16/UTF-8 строк |

`decoded/` — **только для чтения и поиска**. Правки вносятся в Simple-Scada
через `project/` (или в исходном архиве), иначе они не попадут в проект.

## Инфраструктура (из `Project.spr`)

- **Архив:** PostgreSQL, БД `SlicorpBD`, `localhost`, пользователь `postgres`
- **OPC DA:** `TENSO_OPC_DA2.1` на `localhost` — весовой терминал Тензо-М
- **OPC UA:** `opc.tcp://192.168.40.200:4840` — ОВЕН ПЛК210 (Arm32, Linux, CODESYS V3),
  namespace `urn:plc200silkorp:Owen:PLC210...:OPCUA:Server`
- **Единицы:** Амперы, Гц (задание частоты ЧП), кг, ТОННЫ, %, секунды, счётчик
- Контроль связи с ПЛК — `StartPing('192.168.40.200', 1000, CheckBox2)`
  (см. `decoded/scripts/PingControl.pas`, `PingPLC16FlorStart.pas`)

## Состав автоматизации

Оборудование (по префиксам тегов):

| Префикс | Оборудование | Кол-во |
|---------|--------------|--------|
| `N`  | нории | 10 |
| `C`  | аспирация | 14 |
| `T`  | транспортёры (прямой/реверс) | 20 |
| `*Latch` | задвижки/клапаны: T1, T4, T4Clap, T5, T5Clap, T6, T7 | 7 групп × 8–10 |
| `T1..T7 Freq` | частотные преобразователи (задание частоты) | 7 |

Один экран `Управление` (`Page2`) + подстраница, окно `FreqWindow`
(«Задание частоты частотных преобразователей», поля Т1…Т7),
~455 текстовых и ~420 числовых полей, 60 бункеров (`Tank`), таблицы.

Отчёты: `VesReport` (за смену) и `VesReportInterval` (за интервал) —
колонки «Счётчик весов», «Счётчик оператора» и др., источник «Данные».

## Логика управления механизмом

`StatusN*/C*/T*` — состояние (`.AsInt`), используется в скриптах
`TextStatus*_OnDataChange`:

| Код | Состояние | Цвет |
|-----|-----------|------|
| 1 | В работе (А) — автоматический режим | зелёный |
| 2 | В работе (М) — местный режим | жёлтый |
| 3 | Стоп (М) | красный |
| 4 | Стоп (А) | красный |
| 10 | Авария | красный |

`StatusStart*` — команда пуска:

| Код | Значение |
|-----|----------|
| 5 | команда на включение выдана |
| 6 | отмена пуска |

Кнопка пуска (`StartButton*_OnClick`) проверяет неактивность выхода
контроллера (`RelayOut*.AsBool = False`) и отсутствие местного включения
(`Status* = 4`), затем выставляет `StatusStart* := 5` и поднимает
`ManualStartStatus` — таймер предупредительной сигнализации перед пуском.
Повторное нажатие при `StatusStart* = 5` отменяет пуск (`:= 6`).

Прочие семейства тегов на механизм: `RelayOut*`, `RelayIn*`,
`RelayStopIn*` (питание стоповой кнопки), `RelayAlarm*`, `AlarmStatus*`,
`StatusAlarm*`, `StartTime*`, `AlarmTime*`, `RPMTimerT*` (контроль оборотов).

Сообщения (`Messages.smg`) сгруппированы: «Пуск стоп нории / аспирация /
транспортеры», «Сообщения состояния механизмов», «Служебные сообщения».
На механизм — «Пуск», «Отмена пуска», «Стоп», «Отсутствие питания стоповой
кнопки».

## Как воспроизвести расшифровку

```bash
apt-get install -y unrar                       # 7-Zip 23.01 не берёт этот RAR5
unrar e -y BKHP_SILKORP_original.rar out/      # имена с кириллицей ломают -x
python3 tools/dump_simplescada.py out/Scripts.ssc > scripts.txt
```

Формат: последовательность строк `uint32 len` + `len` символов UTF-16LE
(в заголовках — `len` байт UTF-8). Скрипт хранится как имя обработчика,
служебный маркер и построчно текст на Pascal-подобном языке Simple-Scada.

## Что дальше

Папка называлась «для доработки» — конкретный объём доработки не задан.
Правки в бинарные `project/*` вносятся только через редактор Simple-Scada;
расшифровка в `decoded/` нужна для навигации, диффов и код-ревью.
