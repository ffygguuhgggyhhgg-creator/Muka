# Фотографии для сайта

Сюда кладутся снимки производства. Главная страница ждёт три файла:

| Файл | Что на снимке |
|---|---|
| `melnitsa.jpg` | Размольный цех: вальцовые станки, рассевы, общий план линии |
| `elevator.jpg` | Элеватор снаружи, силосы, приёмка зерна |
| `otgruzka.jpg` | Погрузка: муковоз под наливом, биг-бэг на погрузчике или причал |

Пока файла нет, блок с ним просто не показывается. Битых картинок и пустых
рамок на сайте не будет, вёрстка вокруг останется целой. Как только файл
появится в этой папке, снимок встаёт на место сам, править код не нужно.

## Требования к файлам

- Ширина 1600 px, этого достаточно для любого экрана
- Формат `.jpg`, качество 80. Тяжелее 300 КБ файл делать не стоит
- Горизонтальный кадр, пропорции близко к 4:3
- Снимать при дневном свете, без вспышки в лоб

## Как добавить новый снимок

Открыть `src/pages/public/HomePage.tsx`, найти массив `productionShots` и
дописать строку:

```ts
{
  src: '/photo/prichal.jpg',
  alt: 'Речной причал, погрузка баржи',
  caption: 'Отгрузка с причала',
}
```

Поле `alt` обязательно: его читают поисковики и программы для незрячих.
Описывать нужно то, что действительно на снимке.

## Чего здесь быть не должно

Стоковых фотографий чужих заводов и картинок, сгенерированных нейросетью.
Покупатель приезжает на производство и сравнивает с тем, что видел на сайте.
Лучше меньше снимков, но своих.
